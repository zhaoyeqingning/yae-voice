# 开题报告

题目：Yae voice agent  
方向：流式生成、播放，延迟优化  
仓库：[https://github.com/zhaoyeqingning/yae-voice](https://github.com/zhaoyeqingning/yae-voice)

## 1. 要做什么

做一套ai语聊系统。近两个月先把流式语音链路做稳，支持实时打断，看情况加并发设计、记忆系统、玩法流程等等。

## 2. 功能范围

至少交付一条能跑通的对话链路：

1. 麦克风采集用户语音输入，本地按策略截断，流式交给转写。
2. 流式转写结果进入流式模型，模型按字返回。
3. 切段后分段合成，第一小段在模型说完之前开始合成。
4. 播放走统一的播放接口。
5. 新一轮取消上一轮尚未播出的音频。只有真正开始播放的回复才写入对话历史。
6. 每一轮追加一条耗时记录，包含听、想、说、合计，以及旧音频是否被播出，方便进行延迟优化。

## 3. 可能的扩展

并发。链路主体是 IO 密集，并发做好会话隔离、队列设计就可以。 

记忆。先只记住已经开始播放的话。被打断、没播出来的回复不进历史，避免模型以为自己说过。扩展可以看后续使用场景做适应性的记忆策略。

玩法。服务端主动设计具体的交互流程，比如由服务端主动驱动voice agent来扮演一个占卜师，构建半开放式的占卜体验。
